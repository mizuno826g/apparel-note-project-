# AIと一緒にブランドの世界観を作る｜コンセプト設計からキャッチコピーまで

ブランドを始めようとするとき、多くの人がいきなり「どんな服を作るか」を考えます。でも実は、その前に決めておくべきことがあります。

**「このブランドは何者で、誰に向けて、何を伝えるのか」**——これがコンセプトです。

コンセプトが曖昧なままだと、SNSで何を発信すればいいかわからなくなります。撮影の方向性も迷う。コピーも決まらない。気づいたら「なんとなくストリート系っぽいもの」を発信しているだけで、何も刺さっていない状態になります。

この記事では、**AIを相棒にしてブランドコンセプトを言語化・具体化するワークフロー**を全部見せます。

---

## 失敗談：「なんとなくストリート系」で始めて迷走した話

正直に言います。ぼくのブランドの最初の1年間は、コンセプトがほぼ決まっていませんでした。

「ストリート系のグラフィックTシャツ」というふわっとした方向性だけで動き始めて、Instagramも商品ラインナップも、「なんかカッコいい」という感覚だけで作っていました。

結果どうなったか。フォロワーが増えない。増えたとしても、リピーターにつながらない。商品を買ってくれた人が「次のラインナップを楽しみにしてる」と言ってくれることがなかった。それは当然で、**ブランドの軸がなければ、お客さんも「このブランドに期待するもの」が持てない**からです。

2年目に入って初めてコンセプトシートを作り直しました。ターゲット、世界観、言葉のトーン、視覚的なトンマナ——これを全部紙に書き出したとき、「あ、ここまで考えてなかったんだ」と気づきました。遠回りしました。

コンセプトが固まると、あらゆる判断が速くなります。「この投稿はブランドに合うか」「この商品はコンセプトに合っているか」を判断する軸ができるからです。

---

## AIとブランド設計する全体ワークフロー

手順はこの順番で進めます。

1. ターゲット設定（AIと壁打ち）
2. ブランド名の候補を出す
3. キャッチコピー・タグラインを磨く
4. コンセプトシートにまとめる

一気にやろうとせず、**1〜2日かけてステップを踏む**のが最終的な質を上げるコツです。

AIへの指示（プロンプト）は、以下にすべてそのまま使える形で掲載します。[ ]の中を自分のブランドに合わせて書き換えてください。

---

## STEP 1：ターゲット設定のためのAI壁打ち

ターゲット設定で多い失敗は「20代のストリート好き男性」のような大きなくくりで止まること。これでは刺さる言葉が選べません。もっと「一人の人間」を描写するイメージで詰めます。

以下のプロンプトをそのまま使ってください：

```
あなたはブランドコンサルタントです。
私がアパレルブランドのターゲット像を具体化するのを手伝ってください。

【ブランドのざっくりとした方向性】
[例：ストリート、グラフィック中心、東京の若者文化がベース]

以下の項目を埋めながら、ターゲットとなる「一人の人物」を描写してください：
- 年齢・性別
- 職業・生活スタイル
- ファッションに対する価値観（何を重視するか）
- よく使うSNS・インフルエンサー（具体的な名前でOK）
- 休日の過ごし方
- 普段の悩み・コンプレックス
- このブランドに何を求めているか

最後に、このターゲットが「思わず反応するキーワード5つ」を出してください。
```

AIが出した回答を読んで「これは自分のターゲットとちょっと違う」と感じたら、そのまま「この部分が違います。実際は〇〇です」と返してください。**対話を重ねるほど精度が上がります。**

---

## STEP 2：ブランド名候補をAIに出させる

ブランド名を決めるのに何週間も悩む人がいますが、まず**数で圧倒する**のがコツです。

```
ストリートアパレルブランドの名前候補を100個出してください。

【条件】
- コンセプト：[例：都市の孤独と解放感、東京のアンダーグラウンド文化]
- ターゲット：[例：20代前半、サブカル・アート好き]
- 言語：英語・日本語・造語どれでも可
- 文字数：1〜10文字程度
- 避けたいもの：すでに有名なブランドに似た名前、ありきたりな英単語の組み合わせ

出力形式：番号付きリストで100個。説明は不要。名前だけ。
```

100個のうち、「これは違う」を消していくと、残るものが自然と候補に絞られます。気になるものが3〜5個残ったら、次のプロンプトで深掘りします：

```
以下のブランド名候補について、それぞれ以下を答えてください：
- 名前の意味・語源
- どんな世界観・印象を持つか
- 検索しやすさ・発音しやすさの評価（5段階）
- 類似した既存ブランド名があれば指摘してください

候補：[残った候補を列挙]
```

最終決定は必ず自分でしてください。AIはあくまで「選択肢を広げる道具」です。

> 注意：ブランド名を決めたら、必ず商標の観点から既存登録との重複がないか確認しましょう。特許庁のJ-PlatPat（https://www.j-platpat.inpit.go.jp/）で検索できます。AIは商標の重複を完全に確認できません。

---

## STEP 3：キャッチコピー・タグラインをAIで磨く

タグライン（ブランドの一言コピー）は、ブランドの哲学を圧縮したものです。

```
以下のブランドコンセプトに合うタグライン（キャッチコピー）を20個作ってください。

【ブランド名】[例：VOIDTOKYO]
【コンセプト】[例：東京の裏路地に生きる人間の孤独と美しさ]
【ターゲット】[例：20代前半男性、自分なりのスタイルを持つ人]
【言語】日本語・英語どちらでも可
【文字数】5〜20文字程度
【トーン】クール、詩的、少し反骨的

出力：番号付きリストで20個。各コピーに一言コメントをつけて。
```

AIが出してくれたコピーの中で「これは惜しい」というものがあれば、こう追いかけます：

```
「[気に入ったコピー]」という方向性は好きですが、もう少し[例：都市的な冷たさ]を足したいです。
このコピーをベースに10パターンのバリエーションを出してください。
```

**人間が手を加えるポイント：** AIが出すコピーは「正しいけど当たり前」になりがちです。最後に「自分のブランドの体験から生まれた言葉」を1〜2語差し込むことで、一気にオリジナリティが出ます。たとえば特定の土地名、自分だけが使う造語、思い入れのある言い回しなど。

---

## STEP 4：コンセプトシートをAIに作らせる

ここまでの内容を1枚にまとめます。このシートは自分の判断基準として、またフリーランスの協力者（デザイナー・カメラマンなど）との情報共有にも使えます。

```
以下の情報をもとに、アパレルブランドのコンセプトシートを作成してください。

【ブランド名】[ブランド名]
【タグライン】[決定したタグライン]
【ブランドコンセプト（3〜5文）】[コンセプトの説明]
【ターゲット像】[ターゲットの詳細]
【カラーパレット（HEXコードまたは色名）】[決定した色]
【フィードトンマナ】[Instagramのルール]
【発信のトーン＆マナー】[言葉の使い方・避けること]
【競合・参考ブランド】[3〜5ブランド]

出力形式：
各項目を整理してコンパクトにまとめてください。
印刷して使えるA4想定のレイアウト感で。
```

このシートを一度作っておくと、あらゆる判断の速度が上がります。「この投稿はブランドに合うか」「この商品はコンセプトに合っているか」をシートを見ながら即座に判断できるようになります。

---

## 「AIっぽくならない」仕上げ方

AIが生成したコピーやコンセプト文には、どうしても「正確だけど個性がない」という特徴が出やすいです。これを防ぐコツを3つ。

**AIっぽさを消す3つのポイント：**

1. **固有名詞を入れる**：地名、好きなアーティスト、実際に行ったことがある場所など。「東京」より「下北沢の路地裏」のほうが刺さる。
2. **体験から来た言葉を1つ足す**：「自分はなぜこのブランドを作ったのか」の核心から来る言葉。AIは作れない。
3. **削る**：AIは説明しすぎる傾向があります。完成したコピーを3割削ると大体よくなります。

## まとめ

```
【AIでブランドコンセプトを作る ワークフローチェックリスト】

□ ターゲット像を「一人の人間」レベルで具体化した（AIと壁打ち）
□ ブランド名の候補を最低30個出して絞り込んだ
□ 最終候補のブランド名を商標検索で確認した（J-PlatPat）
□ タグラインを20個以上出して最良のものを選んだ
□ AIが出したコピーに自分の言葉・固有名詞を足して磨いた
□ コンセプトシートを1枚にまとめた
□ コンセプトシートをデザイナー・カメラマンなどと共有した
```

コンセプトは一度作ったら終わりではなく、ブランドの成長とともに磨いていくものです。でも**最初に「軸」を作っておくことで、迷ったときに立ち返れる地図が手に入ります。**
