# アパレル起業にいくら必要？国内・中国OEM・関税まで全部公開

「アパレルって意外と安く始められる」という話を聞いたことがある一方で、「思ったより全然お金がかかった」という声も同じくらいよく聞きます。

どちらが正解かというと、**両方が正しいんです。** アパレルには「思ったより安い部分」と「思ったより高い部分」が混在していて、それを事前に把握できるかどうかで、ブランドの立ち上がりが大きく変わります。

この記事では、国内生産・中国OEM・関税の仕組みまでコストの全体像を包み隠さず公開します。数字を見ながら、自分の予算感と照らし合わせてください。

---

## 失敗談：コスト計算が甘くて、利益が出なかった話

最初に国内ボディ＋プリントでTシャツを30枚作ったとき、計算したのはボディ代とプリント代だけでした。

実際に届いてから気づいたのが、**タグ代・梱包資材代・送料（発送）・決済手数料**の存在です。販売価格はそれなりに設定していたはずなのに、全部の費用を足したら利益がほぼ出ていない……という結果に。

「なんで利益が出ないんだろう」と計算し直したら、コスト項目の漏れが原因でした。**コスト計算は「作る費用」だけじゃない。届けて・売って・回収するまでのすべてが含まれます。** この教訓から、今は必ずコスト項目を網羅してから動くようにしています。

---

## まずコスト項目の全体リスト

アパレルのコストは大きく「製造コスト」「間接コスト」「販売コスト」の3層に分かれます。

- **製造コスト**
  - ボディ代（無地Tシャツ等の素材費）
  - プリント・加工代（印刷・刺繍等）
  - オリジナルタグ・ネームタグ代
  - 副資材代（ボタン・ファスナー等、OEMの場合）
  - 検品費（OEMの場合）

- **輸送コスト（OEMの場合）**
  - 海上輸送費または航空輸送費
  - 関税
  - 消費税（輸入時）
  - 通関代行手数料

- **間接コスト**
  - デザイン費（外注する場合）
  - サンプル代（OEMの場合は必須）
  - 撮影費（商品写真）
  - 梱包資材代（ポリ袋・ダンボール・テープ等）
  - 倉庫・保管費（規模が大きくなった場合）

- **販売コスト**
  - ECサイトの利用料・月額費用
  - 決済手数料（クレジットカード決済等）
  - 発送費（お客さんへの配送料）
  - SNS広告費（ある場合）
  - 返品対応コスト

## 国内生産のコスト実例

### ケース①：30枚ロット（Tシャツ・1カラー）

| コスト項目 | 目安感 | 備考 |
|----------|--------|------|
| ボディ代（1枚あたり） | 中程度 | GILDANやPrintstarなど |
| プリント代（1枚あたり） | 中程度 | DTGまたはシルクスクリーン（1色） |
| オリジナルタグ代 | 小〜中 | ネームタグ・下げ札など |
| 梱包資材（OPP袋等） | 小 | |
| 国内送料（仕入れ時） | 小 | |
| **合計（1枚あたり）** | **中〜高め** | 小ロットなので単価が上がりやすい |

> 💡 **ポイント**
> 30枚ロットは「テスト」と割り切ること。1枚あたりのコストは割高でも、売れるデザインを見つけるための情報収集コストと考えましょう。

### ケース②：100枚ロット（Tシャツ・1カラー・シルクスクリーン1色）

| コスト項目 | 目安感 | 備考 |
|----------|--------|------|
| ボディ代（1枚あたり） | 低〜中 | まとめ買いで単価が下がる |
| プリント代（1枚あたり） | 低〜中 | 版代が枚数で割れてコスト下がる |
| オリジナルタグ代 | 小 | 枚数が増えると単価が下がる |
| 梱包資材 | 小 | |
| **合計（1枚あたり）** | **中程度** | 30枚より1枚あたりコストが下がる |

国内生産の場合、**100枚前後から1枚あたりのコストが安定してくる**ことが多いです。

## 中国OEMのコスト実例

中国OEMは「完全オリジナル」が作れる分、コスト構造が複雑です。

| コスト項目 | 目安感 | 備考 |
|----------|--------|------|
| サンプル代 | 中〜高 | 生産前の確認用。複数修正が入ると増える |
| 生産コスト（1枚あたり） | 低め（量産時） | ロット数が多いほど単価が下がる |
| 検品費 | 小〜中 | 日本側エージェントや現地検品サービスを使う場合 |
| 海上輸送費（船便） | 中程度 | リードタイム長め（4〜6週間） |
| 航空輸送費（空輸） | 高め | 速い（5〜10日）がコスト高 |
| 関税 | 品目による | 後述 |
| 消費税（輸入時） | 別途課税 | 後述 |
| 通関代行手数料 | 小〜中 | 通関業者（乙仲）を利用する場合 |

### 海上輸送 vs 航空輸送

| | 海上輸送 | 航空輸送 |
|--|---------|---------|
| リードタイム | 4〜6週間（中国→日本） | 5〜10日 |
| コスト | 低い | 高い（目安で3〜5倍以上） |
| 向いているケース | 計画的な量産時 | 急ぎ・少量・サンプル確認時 |

OEMは**リードタイムを含めた総コストで比較する**ことが大切です。

## 関税の仕組み

中国からアパレルを輸入する場合、**関税と消費税が課されます。** これを知らずに計算すると、コストが大幅にズレます。

### 関税率の調べ方

日本の関税率は品目ごとに決まっており、**財務省が運営する「日本税関」のWebサイト（[customs.go.jp](https://www.customs.go.jp)）** で調べることができます。「輸入統計品目表（実行関税率表）」から品目に対応するHSコード（国際的な品目分類番号）を調べると関税率がわかります。

例として、コットン製のTシャツ（HSコード 6109.10）は、一般税率で**10.9%** が適用されるケースが多いです（税率は更新される場合があるため、必ず最新の実行関税率表で確認してください）。

### 消費税（輸入時）の計算

輸入時には、関税を含めた課税価格に対して消費税10%が課されます。計算式は以下のとおりです。

```
消費税（輸入時）の計算式

課税価格 = 輸入品の価格（CIF価格：商品代金＋保険料＋輸送費）
関税額 = 課税価格 × 関税率
消費税額 = （課税価格 + 関税額）× 10%

合計税額 = 関税額 + 消費税額
```

> 💡 **ポイント**
> CIF価格（商品代金＋輸送費＋保険料）が課税の基準になります。送料まで含めた金額が計算のベースです。

### 少額輸入の免税（個人輸入の場合）

個人使用目的の輸入で課税価格が1万円以下の場合は関税・消費税が免除される場合がありますが、**販売目的の商業輸入にはこの免税は適用されません。** ビジネス目的の仕入れは正規に申告・納税することが必要です。

## コストを下げるための現実的な方法

```
コスト削減チェックリスト

【製造コスト】
□ デザインをできる限り自分でつくる（外注費の削減）
□ 印刷の色数を絞る（シルクスクリーンの版代を減らす）
□ ロット数を増やしてスケールメリットを得る（ただし在庫リスクと要バランス）
□ 最初から量産せず、テスト販売→追加発注の順で動く

【OEMコスト】
□ サンプル修正回数を減らす（デザインデータを精密に作る）
□ 海上輸送を使う（急がないなら空輸より大幅安）
□ まとめて発注してコンテナを効率よく使う

【間接コスト】
□ 梱包資材はまとめ買いで単価を下げる
□ 商品撮影は最初はセルフで行い、軌道に乗ってから外注する

【販売コスト】
□ ECサイトの選定で月額費用を抑える（BASEやSTORESなど初期費用が低いサービスを活用）
□ 送料設定を最初から適切に行い、「送料込み」にして赤字を出さない
□ 返品対応のルールを事前に決めておく（対応コストの予測）
```
