# 入稿データって何？アパレル印刷で絶対必要な知識をゼロから解説

アパレルを実際に作るとき、「デザインさえできたら業者に送ればいい」と思っていませんか？

じつは「デザインを作る」と「入稿データを作る」はまったく別の話です。**データの仕様が間違っていると、刷り直しになるか、最悪の場合は印刷が崩れたまま納品されます。** 刷り直しは時間もコストも2倍になります。これを防ぐには、入稿データの基本を最初に押さえておくことが一番の近道です。

この記事では、入稿データの基本からツール選びまで、ソースで確認できた公式情報のみを使ってゼロから解説します。

---

## 入稿データとは何か

「入稿データ」とは、**印刷業者が印刷機を動かすために使うデザインファイル**のことです。「とりあえず画像を送ればいい」というわけではなく、解像度・カラーモード・ファイル形式などの仕様が業者ごとに定められています。

### ラスターとベクター：2種類のデータ形式

画像データには大きく2種類の形式があります。この違いを理解しているかどうかで、入稿ミスの8割は防げます。

**仕組み**
　ラスター（ビットマップ）：ピクセル（点）の集まりで画像を表現
　ベクター：数式で形を定義（点と線）

**拡大すると**
　ラスター（ビットマップ）：ぼやける（解像度に依存）
　ベクター：ぼやけない（どんな大きさでも鮮明）

**代表ツール**
　ラスター（ビットマップ）：Photoshop・GIMP
　ベクター：Illustrator・Inkscape

**代表ファイル形式**
　ラスター（ビットマップ）：JPEG・PNG・PSD
　ベクター：AI・EPS・SVG

**アパレル印刷での使い方**
　ラスター（ビットマップ）：写真・複雑なテクスチャ系
　ベクター：ロゴ・シンプルなグラフィック


**ロゴや文字は必ずベクターで作りましょう。** ラスターで作ると、印刷サイズに拡大した瞬間にボケが発生します。

## 主要業者の公式入稿仕様

### TMIX（オリジナルTシャツ）

公式サイト（https://tmix.jp）で確認できた入稿仕様は以下のとおりです。

**推奨解像度**　等倍で**300dpi程度**

**カラーモード**　**CMYK**

**対応ファイル形式（Illustrator）**　バージョン8〜10、CS2〜CS6、CC

**対応ファイル形式（Photoshop）**　PSD

**アップロード上限**　最大20MB（デザインエディタ経由）

**フォント処理**　**アウトライン化必須**（フォントが相手環境にないと別フォントに置き換わる）

**線の太さ**　**2pt（0.7mm）以上**（それ以下はかすれる可能性あり）

**画像の埋め込み**　**埋め込み形式で保存**（リンク配置はリンク切れの原因になる）


> 出典：[TMIX データ入稿ページ](https://tmix.jp/for-customers/design-simulator/data-submission)、[解像度について](https://tmix.jp/info/resolution)

### オリジナルプリント.jp

公式サイト（https://originalprint.jp）の完全データ入稿規定で確認できた仕様は以下のとおりです。

**対応ファイル形式**　**.ai / .psd / .pdf / .png**

**解像度**　**原寸で200dpi以上**（一部アイテムは400dpi以上）

**カラーモード（完全データ入稿）**　**CMYK**

**カラーモード（デザインツール経由）**　**RGB**（デザインツールにアップロードする場合はRGBで保存）

**オブジェクトの太さ・間隔**　**1mm以上**（約2.84pt以上）

**フォント処理**　**アウトライン化必須**

**画像の配置**　**埋め込み**（リンク配置は不可）

**複雑なパス・パターン**　**ラスタライズ必須**


> 出典：[オリジナルプリント.jp 完全データ入稿規定](https://originalprint.jp/store.php/page/complete-design)、[カラーモードに関するFAQ](https://support.originalprint.jp/draft/draft-completedesign-color/)

## 解像度・カラーモード・ファイル形式：3つの基本を理解する

### ① 解像度

dpi（ドット・パー・インチ）とは、1インチの中にどれだけ細かくピクセルを詰め込むかを示す単位です。

- **Web用（SNS・Webサイト表示）：72〜96dpi** で十分
- **印刷用：200〜300dpi以上** が必要（業者によって異なる）

**Photoshopでキャンバスを新規作成するとき、最初に解像度を設定してください。** 72dpiで作ったものを後から300dpiに変換しても、解像度は実質上がりません（ピクセル数は増えますが、元の情報量は変わらないためボケたままになります）。

### ② カラーモード

- **RGB（レッド・グリーン・ブルー）**：光で色を表現。スマホやモニターに向いている
- **CMYK（シアン・マゼンタ・イエロー・ブラック）**：インクで色を表現。印刷に向いている

モニターで見るとキレイな色でも、RGBで作ったデータをCMYKの印刷機で出力すると、**色が思ったよりくすんで出る**ことがよくあります。一方、DTGやDTF印刷ではRGB入稿を求める業者もあります。上で示した仕様のとおり、業者・入稿方法によって指定が変わるため、**入稿前に必ず業者の仕様ページを確認してください。**

### ③ ファイル形式

****.ai**（Illustrator）**
　特徴：ベクターデータ。業者が最も受け取りやすい形式
　向いている用途：ロゴ・文字・シンプルなグラフィック

****.psd**（Photoshop）**
　特徴：ラスターデータ。写真・複雑なテクスチャ向き
　向いている用途：写真合成・テクスチャ系デザイン

****.pdf****
　特徴：Illustratorからの書き出しに使われることが多い
　向いている用途：完全データ入稿全般

****.png****
　特徴：背景透過が可能。DTF転写によく使われる
　向いている用途：DTG・DTF入稿

## 印刷方法別の入稿注意点

### シルクスクリーン

- **色数ごとにデータを分解する必要がある**（「色分解」）
- グラデーションはそのまま使えない（ドット表現で疑似再現するか、デザインを変える）
- Illustratorでのベクター入稿が最もスムーズ
- 特定の色（蛍光色・金・銀）を使いたい場合は「特色（スポットカラー）」の指定が必要

### DTG・DTF

- **背景は透過処理（PNG透過）**にする必要がある
- 黒やダーク系の生地に印刷する場合、白インクをベースとして下刷りするため、データ上の白処理について業者に事前確認が必要

## 入稿前チェックリスト

```
【基本スペック】
□ 解像度は業者指定（TMIX：300dpi推奨 / オリジナルプリント.jp：200dpi以上）を満たしているか
□ カラーモードは業者指定に合っているか（CMYK / RGB）
□ ファイル形式は業者が指定する形式か（AI / PDF / PNG / PSD 等）

【デザイン内容】
□ 文字（テキスト）はアウトライン化（フォントをパスに変換）済みか
□ 配置している画像は「埋め込み」になっているか（リンク切れ注意）
□ 線の太さがTMIXなら2pt（0.7mm）以上、オリジナルプリント.jpなら1mm以上か

【シルクスクリーン専用】
□ 色数を正しく確認しているか
□ 色ごとにレイヤーを分けているか
□ グラデーション・影が含まれていないか（ある場合は業者に相談）
□ 特色（蛍光・金・銀）を使う場合、特色指定が明記されているか

【DTG / DTF専用】
□ 背景は透過処理（PNG透過）されているか
□ 暗い生地の場合、白インクの処理について業者に確認済みか

【最終確認】
□ 入稿前に業者の公式仕様ページを再確認したか
□ ファイル名にデザイン名・バージョンを記載しているか
```

## まとめ

入稿データで最初に押さえるべき3点は「解像度・カラーモード・ファイル形式」です。ただし、業者によって指定が異なるため、**入稿する業者の公式仕様ページを必ず確認すること**が最大の失敗防止策です。

ツールはコストと習熟度のバランスで選びましょう。まずInkscape（無料）でベクターの基礎を学び、売上が立ってきたらAdobe Illustratorへ移行するのが現実的な順番です。
