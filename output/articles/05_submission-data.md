# 入稿データって何？アパレル印刷で絶対必要な知識をゼロから解説

デザインができた。あとは業者に送るだけ——そう思っている人に、最初に現実を伝えます。

**「デザインを作る」と「入稿データを作る」はまったく別の作業です。**

仕様が合わないデータを送ると、印刷が崩れたまま納品されるか、刷り直しになります。どちらも時間とお金を2倍以上消費します。この記事では、入稿ミスを防ぐための知識を、初めての人でも理解できる順番で解説します。

---

## 「データミスで刷り直し」—— 実際に起きること

アパレルの入稿ミスで一番多いのが「解像度不足」です。

スマホやパソコンのモニターで見るぶんには十分きれいに見えるのに、印刷してみると全体がぼんやりしている——というケースが後を絶ちません。理由はシンプルで、**モニター表示に必要な解像度（72〜96dpi）と印刷に必要な解像度（200〜300dpi以上）はまったく違う**からです。

問題はミスの代償の大きさにあります。

たとえば50枚のTシャツを刷り直す場合を考えてみましょう。

**💰 コストシミュレーション：刷り直しが発生した場合**
- Tシャツ本体（1枚800円）× 50枚 = 40,000円
- 印刷代（1枚600円）× 50枚 = 30,000円
- 初回製造費の合計 = **70,000円が無駄になる**

これに加えて、纵期が2〜3週間延びることで、予定していた販売スタートが遅れます。入金が遅れ、次のロットへの投資も後ろ倒しになります。

一方、**Adobeのツールに毎月払うコスト（Illustrator：月3,280〜4,980円）と、それを正しく使いこなすために使う時間**を比べれば、どちらが賢い投資かは明らかです。入稿データの作り方を一度身につけてしまえば、2回目以降はコストゼロです。

---

## 入稿ミスが起きる3大原因

長年アパレルの製造現場でよく聞く失敗パターンは3つに集約されます。

**① 解像度が低い**
Web用のデザイン（72dpi）をそのまま入稿している。モニターでは問題なく見えるため、ミスに気づかない。

**② カラーモードが違う**
デザインをRGBで作ったまま入稿している。印刷機はCMYKで動くため、色がくすんで出る。（ただし業者・印刷方式によってはRGB指定の場合もある。必ず確認が必要。）

**③ フォントをアウトライン化していない**
自分のパソコンにあるフォントを使って作成し、そのまま送っている。受け取った業者側にそのフォントがなければ、別のフォントに自動置換される。

この3つを防ぐだけで、入稿ミスの大半は回避できます。

## ラスターとベクター：2種類のデータ形式

画像データの形式は大きく2種類あります。この違いを最初に理解しておくと、ツール選びとファイル形式の選択が一気にクリアになります。

**仕組み**
　ラスター：ピクセル（点）の集まりで画像を表現
　ベクター：数式で形を定義（点と線）

**拡大すると**
　ラスター：ぼやける（解像度に依存）
　ベクター：ぼやけない（どんな大きさでも鮮明）

**代表ツール**
　ラスター：Photoshop・GIMP
　ベクター：Illustrator・Inkscape

**代表ファイル形式**
　ラスター：JPEG・PNG・PSD
　ベクター：AI・EPS・SVG

**アパレルでの使い分け**
　ラスター：写真・複雑なテクスチャ系
　ベクター：ロゴ・シンプルなグラフィック

**ロゴや文字は必ずベクターで作ってください。** ラスターで作ると、印刷サイズに拡大した瞬間にボケが発生します。

## 解像度・カラーモード・ファイル形式：3つの基本

### ① 解像度

dpi（ドット・パー・インチ）は、1インチの中にどれだけピクセルが詰まっているかを示す単位です。

Web表示用は72〜96dpiで十分ですが、印刷用は200〜300dpi以上が必要です。

**重要な注意点：** 72dpiで作ったキャンバスを後から300dpiに変換しても、実質的な解像度は上がりません。ピクセル数が増えるだけで、元の情報量は変わらないためボケたままになります。**最初のキャンバス作成時に解像度を設定する**のが正しい順番です。

### ② カラーモード

RGB（レッド・グリーン・ブルー）は光で色を表現するモードで、スマホやモニターに向いています。CMYK（シアン・マゼンタ・イエロー・ブラック）はインクで色を表現するモードで、印刷に向いています。

モニターで見るとキレイな色でも、RGBのままCMYKの印刷機で出力すると色がくすんで出ることがよくあります。ただしDTGやDTF印刷ではRGB入稿を求める業者もあるため、業者ページを必ず事前確認してください。

### ③ ファイル形式

**.ai（Illustrator）**
　業者が最も受け取りやすいベクター形式。ロゴ・文字・シンプルなグラフィックに。

**.psd（Photoshop）**
　写真・複雑なテクスチャに向いたラスター形式。

**.pdf**
　Illustratorからの書き出しに使われることが多い。完全データ入稿全般に。

**.png**
　背景透過が可能。DTF転写やDTG入稿に。

## 印刷方法別の入稿注意点

### シルクスクリーン

- **色数ごとにデータを分解する必要がある**（色分解）
- グラデーションはそのまま使えない（ドット表現で疑似再現するか、デザインを変える）
- Illustratorでのベクター入稿が最もスムーズ
- 蛍光色・金・銀など特定の色を使いたい場合は「特色（スポットカラー）」の指定が必要

### DTG・DTF

- **背景は透過処理（PNG透過）**にする必要がある
- 黒やダーク系の生地に印刷する場合、白インクをベースとして下刷りするため、データ上の白処理について業者への事前確認が必要

## 入稿前チェックリスト

```
【基本スペック】
□ 解像度は業者指定を満たしているか
   （TMIX：300dpi推奨 / オリジナルプリント.jp：200dpi以上）
□ カラーモードは業者指定に合っているか（CMYK / RGB）
□ ファイル形式は業者が指定する形式か（AI / PDF / PNG / PSD 等）

【デザイン内容】
□ 文字（テキスト）はアウトライン化済みか
□ 配置している画像は「埋め込み」になっているか（リンク切れ注意）
□ 線の太さが業者指定以上か
   （TMIX：2pt/0.7mm以上 / オリジナルプリント.jp：1mm以上）

【シルクスクリーン専用】
□ 色数を正しく確認しているか
□ 色ごとにレイヤーを分けているか
□ グラデーション・影が含まれていないか（ある場合は業者に相談）
□ 特色（蛍光・金・銀）を使う場合、特色指定が明記されているか

【DTG / DTF専用】
□ 背景は透過処理（PNG透過）されているか
□ 暗い生地の場合、白インクの処理について業者に確認済みか

【最終確認】
□ 入稿前に業者の公式仕様ページを再確認したか
□ ファイル名にデザイン名・バージョンを記載しているか
```

## まとめ

入稿データで最初に押さえるべきは「解像度・カラーモード・ファイル形式」の3点です。

ただし、業者によって指定が異なるため、**入稿する業者の公式仕様ページを必ず確認すること**が最大の失敗防止策です。ツールへの投資（月3,000〜5,000円）は、1回の刷り直し損失（数万〜10万円超）と比べれば、圧倒的に低コストな保険です。

**今日のアクション：** 使う予定の業者の入稿仕様ページをブックマークし、カラーモードと解像度の指定を確認してください。
