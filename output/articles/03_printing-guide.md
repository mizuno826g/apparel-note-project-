# 印刷の種類6選｜ブラックマジックって何？コスト・耐久性・見た目を全比較

アパレルブランドを始めた人が最初に迷うのは、じつは「印刷をどれにするか」だったりする。

**印刷方法の選択は、ブランドの質感・コスト・生産ロット数すべてに影響する。** 同じデザインでも、印刷方法が違うだけで見た目の仕上がりが大きく変わるし、予算の組み方も根本から変わってくる。

この記事では、アパレルで使われる主な印刷方法6種類を比較する。仕組み・向いているシーン・コスト・耐久性を整理して、自分のブランドに合った方法を選ぶ判断軸をつかんでほしい。

> **記事内の価格情報は執筆時点（2026年5月）に各社公式サイトで確認したものです。変動する場合があるため、発注前に必ず最新情報をご確認ください。**

---

## 失敗談：版代で大ダメージを受けた話

ブランドを始めて間もない頃、シルクスクリーン印刷でグラフィックTシャツを作ろうとした。デザイナーに描いてもらったイラストは色数が多く7色。「色数が多いほどクオリティが上がるだろう」という素朴な考えでいた。

印刷業者に見積もりを出してもらったら、**版代（印刷用の版を作る初期費用）が色数分かかる**と知った。7色分の版代は想定の3倍以上。さらに小ロットだったので枚数でコストが割れず、1枚あたりの単価が激高になった。

「デザインをシンプルにしておけばよかった」と強く後悔した。**印刷方法を選ぶ前に、デザインの色数と発注枚数を必ずセットで考えること。** これが出発点になる。

## ① シルクスクリーン印刷

アパレル業界で最も歴史が長く、現在も広く使われている印刷方法だ。

### 仕組み

デザインを色ごとに分解し、色の数だけ「版（スクリーン）」を作る。その版にインクを通してTシャツに刷り込む方法。版画をイメージするとわかりやすい。

### 価格・ロットの実例（公式サイト確認済み）

**オリジナルプリント.jp**（公式サイト確認済み）
- 通常シルクスクリーン：最低ロット **100枚〜**
- 版代：**8,250円（税込）/ 1版（1色）**
- 簡易シルクスクリーン（IMシルクスクリーン）：最低ロット **5枚〜**、版代なし
- 調色代：30点以上の注文でDIC・PANTONE色指定可（調色代0円）

**TMIX**（公式サイト確認済み）
- 推奨最低ロット：**30枚〜**
- 版代：**無料**（TMIX独自の仕組みとして明記）
- 参考価格：ヘビーウェイトラグランTシャツ・片面1色
  - 30枚時：**¥1,168（税込¥1,284）〜**
  - 100枚時：**¥883（税込¥971）〜**

### 向いているデザイン
- シンプルなロゴ・文字・幾何学模様
- 大量生産（100枚以上）で版代を単価に分散できる場合
- 単色・少色使いで鮮やかな発色が欲しい場合
- 特色インク（金・銀・蛍光色）を使いたい場合

### 向いていないデザイン
- グラデーションが多用されたデザイン（色数が増えるほど版代増）
- フルカラー写真の再現
- 少量ロット（通常版の100枚未満だとコストが重くなりやすい）

## ② DTG印刷（ダイレクトトゥガーメント）

DTGは「Direct to Garment」の略。専用のプリンターで直接Tシャツにインクを吹き付ける方法だ。

### 仕組み

業務用のインクジェットプリンターが服に直接印刷する。ガーメントプリンターとも呼ばれる。

### 特徴（各社公式情報より確認）
- **版不要・フルカラー対応**：データがあれば1枚から印刷可能
- **インクが生地に染み込む**：プリント面が柔らかく、通気性を損なわない
- **綿素材との相性が良い**：特に淡色の綿生地で高い発色と再現性を発揮
- 濃色・黒地への印刷：白版（下地の白インク層）が必要となり、コストがやや上がる

### 素材制限
綿100%および綿×ポリエステルの混紡（T/C）素材に対応。ポリエステル100%には対応が難しい場合がある（業者によって異なるため確認が必要）。

### 向いているデザイン
- フルカラー写真・グラデーション
- 少量多品種（1枚単位のオーダー、サンプル確認）
- デザインの種類が多く版を作りたくない場合

### 向いていないデザイン
- ポリエステル素材への印刷
- 大量生産（シルクスクリーンと比べ1枚あたりコストが高め）

### 国内主要対応業者
オリジナルプリント.jp、イメージマジック（ODPS）、エドバンファクトリー（各社公式サイト参照）

---

## ③ DTF印刷（ダイレクトトゥフィルム）

### 仕組み

フィルムにCMYK+白インクでデザインを出力し、ホットメルトパウダーを塗布・熱処理して転写シートを作成。その後、熱プレスで衣類に転写する。

### 特徴（イメージマジック公式サイトより確認）
- **白版データ不要**：PNGデータをそのまま使用可能
- **1枚から対応**：在庫リスクを最小化できる
- **素材の幅が広い**：綿、ポリエステル、ナイロンに対応
- **カス取り・リタック不要**：従来の転写プリント手作業工程を削減
- 洗濯耐性が高い

### DTGとの違い

DTGがインクを直接生地に染み込ませるのに対し、DTFは転写シートを経由して貼り付ける。そのため素材の制約が少なく、ポリエステルやナイロンにも印刷できる点が大きな違いだ。

### 向いているデザイン
- フルカラーで素材を選ばず印刷したい
- 小ロット〜中ロット
- ポリエステル混紡アイテムへのプリント
- コットン以外の素材（ナイロンジャケット、バッグ等）

### 向いていないデザイン
- 生地の風合いを最大限生かしたい場合（フィルムが介在するため、プリント面に若干の質感が残る）

## ④ ブラックマジック

### ブラックマジックとはどんな手法か

ブラックマジック（Black Magic）は、DTFとは**別の手法**だ。よく混同されるが、正確には以下のように区別される。

プリズマクリエイティブの公式解説（確認済み）によると、ブラックマジックとは「**主に黒や濃色のTシャツへの印刷において、デザインの黒い部分をあえてインクでプリントせず、ボディの黒地をそのまま活かす特色分解手法**」のことを指す。

### 仕組み
- 6〜12色程度の特色インクを選定してフルカラーを再現する
- 「階調を持ったアンダーベース（白の下引き）」で濃淡を表現する
- 黒部分と黒っぽい部分はマスクデータを作成し、生地の黒を利用する
- この結果、グラフィックが生地と自然に溶け込み、浮き出すような「ソフトで自然な仕上がり」になる

### 特徴
- **深みのある黒表現**：黒インクを使わないため、ボディの黒を活かした奥行きのある仕上がりが得られる
- **インク量が抑えられる**：ベタ面のスジやムラが軽減され、着心地も軽快
- プラスティゾルインクを使うシルクスクリーン手法から始まり、現在は濃色インクジェット技術へも応用されている

### DTFとの関係（重要）
同社の情報によると、ブラックマジックの「黒を生地に溶け込ませる」表現はDTFでは苦手な領域だ。DTFは細かい網点の表現に限界があり、デザインが徐々に生地色と馴染んでいくようなグラデーション表現はDTFでは再現が難しい。

### 向いているデザイン（プリズマクリエイティブ公式コラムより確認済み）
- ステージライトやネオン管など、輪郭が曖昧な幻想的なグラフィック
- 粗めの粒子感やザラザラした質感（ヴィンテージ風）
- 大型プリント（35×45cm以上）で圧迫感を軽減したい場合

### 国内対応業者の例
プリズマクリエイティブ（https://www.prismacreative.jp）、丸昇（https://www.marusho369.com）、ファン・ファクトリー（https://www.originalprint-funfactory.jp）
※ 対応・料金は各社公式サイトでご確認ください。

## ⑤ 昇華転写（サブリメーション）

### 仕組み

転写紙に分散染料インクで印刷し、高温・高圧でポリエステル繊維に染み込ませる手法。インクが気化（昇華）して繊維と一体化するため、インクが生地の一部になるイメージだ。

### 特徴（NISSHA・オリジナルプリント.jp 公式情報より確認済み）
- フルカラー・グラデーション対応
- 洗濯堅牢度が高い（**4〜5級**）
- 生地の風合いを損なわない（インクが繊維内部に染み込むため）
- 縫い目を超えた全面プリントも可能

### 素材制限（重要）
**ポリエステル素材に限定。** 綿素材へは基本的に対応不可だ。「綿対応の昇華転写」技術（SubliToCottonなど）も一部で登場しているが、通常の昇華転写とは別の特殊技術であり、業者ごとに品質差がある。

### 向いているデザイン
- スポーツウェア・ユニフォームなどポリエステル素材のフルカラープリント
- 全面プリント（オールオーバープリント）
- グラデーション・写真品質の表現

### 向いていないデザイン
- 綿Tシャツへの印刷（根本的に素材が合わない）
- 有色生地（インクの混色で発色に影響する場合がある）

## ⑥ 刺繍

### 仕組み

刺繍機（業務用コンピューター刺繍ミシン）を使って、糸でデザインを縫い上げる。

### 料金体系（マーキングラボ公式サイト確認済み）

刺繍は**サイズ（面積）と色数**によって課金される。

**型代（初回のみ）**

| デザインサイズ | 型代 |
|-------------|------|
| 〜9㎠ | 4,400円 |
| 10〜50㎠ | 4,950円 |
| 51〜80㎠ | 5,500円 |
| 81㎠以上 | 要見積もり |

型の保存期間：**5年間**（再注文時は型代不要）

**加工単価（1枚あたり、例：10〜30㎠・3色まで）**

| 注文枚数 | 単価（目安） |
|--------|------------|
| 1〜9枚 | 550円 |
| 50〜99枚 | 420円 |
| 追加色 | 1色につき＋30円 |

素材追加料金：Tシャツ・エプロン0円、一部特殊素材は追加料金あり

### 向いているデザイン
- シンプルなロゴ・文字・マーク
- キャップ・ジャケット・ポロシャツなど
- ブランドの信頼性・高級感を打ち出したい場合

### 向いていないデザイン
- 複雑なグラフィック・グラデーション（糸での再現が困難）
- 大きな面積のデザイン（コストが急増する）

## 印刷方法の選び方フロー

```
Q1. 何枚作るか？
├─ 1〜10枚 → DTG / DTF / 昇華転写（ポリエステルの場合）/ 刺繍（ワンポイント）
├─ 30〜99枚 → DTG / DTF / シルクスクリーン（簡易版）/ 刺繍
└─ 100枚以上 → シルクスクリーン（通常版）/ DTF / 昇華転写

Q2. 素材は何か？
├─ 綿100% → シルクスクリーン / DTG / DTF / 刺繍
├─ ポリエステル / ポリ混紡 → 昇華転写 / DTF / シルクスクリーン
└─ ナイロンなど特殊素材 → DTF（業者に要確認）

Q3. デザインの複雑さは？
├─ ロゴ・文字・シンプルな図形 → シルクスクリーン / 刺繍
├─ フルカラー・写真・グラデーション → DTG / DTF / 昇華転写
└─ 黒地に馴染ませたいヴィンテージ系 → ブラックマジック

Q4. 耐久性の優先度は？
├─ 最高レベルを求める → 刺繍 / シルクスクリーン
├─ 標準レベルで十分 → DTG / DTF
└─ ポリエステルアイテム全面プリント → 昇華転写
```

## まとめ

> **プリント方法は「素材 × ロット数 × デザインの複雑さ」の3軸で選ぶ。**
>
> ① シルクスクリーン：発色◎・耐久性◎。100枚以上の量産で版代を分散。シンプルデザイン向き。
>
> ② DTG：フルカラー対応・版なし・1枚から。綿素材が得意。小ロットテストに最適。
>
> ③ DTF：素材を選ばない万能型。フルカラー対応・小ロットOK。ポリ・ナイロンにも対応。
>
> ④ ブラックマジック：黒地の生地を活かした特殊表現。DTFとは別の手法。ヴィンテージ・幻想系のグラフィックに強い。
>
> ⑤ 昇華転写：ポリエステル専用・発色◎・耐久性◎。全面プリント・スポーツ系向き。
>
> ⑥ 刺繍：高級感・耐久性◎◎。型代あり・面積課金。シンプルロゴのワンポイントに最適。
>
> 迷ったら「まず1枚サンプルで確認」が鉄則。本番ロット前に必ず仕上がりを目で確かめること。
