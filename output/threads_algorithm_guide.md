# Threadsでインプレッションが伸びる書き方・アルゴリズム攻略ガイド

---

## 1. アルゴリズムとプレビューの重要性

Threadsのタイムラインでは、ユーザーは最初の1〜2行（プレビュー部分）を見て、タップするかスクロールするかを瞬時に判断している。

### 「詳細を開く」アクションの価値

Threadsのアルゴリズムは「投稿をタップして詳細を開く（続きを読む）」という行動自体を高く評価する。プレビューで興味を引いて詳細を開かせることで、いいねやコメントが少なくても「おすすめ」に表示されやすくなり、インプレッションが爆発的に伸びる傾向がある。

### 評価される主なシグナル

**詳細の展開**（非常に高い）
→ 冒頭1〜2行で「続きが気になる」状態を作る

**初動の反応**（高い）
→ 投稿後1時間以内の反応が鍵。朝8〜9時などアクティブな時間帯を狙う

**コメント・返信**（高い）
→ 議論や共感を呼ぶテーマ、質問を投げかける

**滞在時間**（中〜高）
→ 2段構成などで最後まで読ませる工夫をする

## 2. プレビュー（冒頭フック）を極める10の型

スクロールを止めるためには、最初の1〜4行で勝負を決める。

### ① 逆説型（常識の逆を突く）
常識や一般的な考え方の逆を提示し、「え、なんで？」と思わせる。
- 例：「〇〇するな」「〇〇は時間のムダです」「できる人ほど〇〇しない」

### ② 数字型（具体性で解像度を上げる）
具体的な数字を入れることで、情報の信憑性と具体性を高める。
- 例：「たった3日で〇〇した方法」「〇〇を5つだけ変えた結果」

### ③ ターゲット型（自分ごと化させる）
特定の悩みや属性を名指しし、「自分のことだ」と思わせる。
- 例：「〇〇で悩んでる人へ」「〇〇な人に共通してること」

### ④ リスク型（損失回避の心理を突く）
「知らないと損をする」「このままだと危険」という危機感を煽る。人は得をする話より、損を避ける話に強く反応する。
- 例：「これ知らない人、マジで損してる」「その〇〇、続けると確実に〇〇します」

### ⑤ 暴露型（秘密や本音を明かす）
普段は言えない本音や裏話を明かすことで、好奇心を刺激する。
- 例：「正直に言うけど、〇〇」「誰も教えてくれない〇〇」

### ⑥ 権威型（実績で説得力を持たせる）
自身の経験や実績を提示し、「この人の話は聞く価値がある」と思わせる。
- 例：「〇〇歴〇〇年の僕が断言します」「〇〇で〇〇を達成した僕が断言します」

### ⑦ 対比型（AとBの違いを提示する）
成功する人と失敗する人などの対比を出し、無意識に自分を当てはめさせる。
- 例：「伸びる人は〇〇する。伸びない人は××する」「〇〇な人と××な人、違いはたった1つ」

### ⑧ 命令型（強い語気で行動を促す）
強い言葉で言い切り、思わず手を止めさせる。
- 例：「今すぐ〇〇してください」「黙って〇〇しろ」

### ⑨ ストーリー型（体験談で引き込む）
物語の始まりを感じさせ、結末が気になるように仕向ける。
- 例：「〇〇だった僕が、〇〇になれた話」「〇〇に全振りした結果、〇〇だった」

### ⑩ 限定型（希少性をアピールする）
「今だけ」「ここだけ」という限定感を出す。
- 例：「今から大事な話します」「ここだけの話、〇〇」

## 3. F-PREP法（最後まで読ませる構成）

| ステップ | 内容 |
|---------|------|
| **F（Hook）** | 冒頭1〜2行でスクロールを止める（上記10の型を活用） |
| **P（Point）** | 「結局何が言いたいの？」を最初に提示する |
| **R（Reason）** | なぜその結論になるのか、読者を納得させる |
| **E（Example）** | 具体的なエピソードや事例で自分ごと化させる |
| **P（Point）** | 最後に要点をまとめ、記憶に残す（保存やフォローを促す） |

### 2段構成テクニック
1つの投稿を「フックと結論」（1段目）と「理由と解説」（2段目）に分ける。「続きを読む」をタップさせやすくなり、アルゴリズム評価が上がる。

## 4. リンクと画像の最適化

### 外部リンクの扱い（重要）
Threadsのアルゴリズムは外部リンク（URL）を本文に貼るとリーチが下がる。

**ベストプラクティス：**
- URLは本文ではなく**返信欄（ツリー）**に貼る
- または**プロフィール欄**に誘導する

### 画像・動画の最適化
- **推奨アスペクト比：** 3:4 または 4:5（Instagramと同様）
- **フルスクリーン動画：** 9:16
- 画像投稿でも必ずテキスト（フック文）を含める

---

## 5. 運用ベストプラクティス

**投稿時間**
朝8〜9時を基本とする。初動の反応を獲得し、夜に向けて拡散させる流れを作る。

**投稿頻度**
1日1投稿を基本とし、質の高いフックと構成を作り込む。乱発してリーチを分散させない。

**Instagramとの連携**
Threads単体で完結させず、Instagramとアイコン・プロフィールを統一し、相互誘導の導線を作る。

## 6. note誘導投稿のフォーマット（このプロジェクト用）

```
【ポスト1（親投稿）】リンクなし
- 上記10の型のどれかを使ったフック（1〜2行）
- F-PREP法で構成
- 2段構成で「続きを読む」を誘発
- 文末に質問またはCTA

【ポスト2（自己リプ）】リンクなし
- 補足・体験談・具体例

【ポスト3（自己リプ）】リンクあり
- noteへの誘導文
- プロフィールのリンクから👆
```
