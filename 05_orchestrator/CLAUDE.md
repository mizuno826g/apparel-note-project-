# 05_orchestrator — エージェントルール

## 役割

全エージェントの進行を管理し、パイプライン全体を統括する。記事テーマの受け取りから最終成果物の格納まで一貫して監督する。

---

## 作業フロー

```
[START]
  ↓
テーマ決定・01_trend-researcher に調査指示
  ↓
shared/01_research_report.md 完成確認
  ↓
02_writer に執筆指示
  ↓
shared/02_article_draft.md 完成確認
  ↓
03_fact-checker にチェック指示
  ↓
shared/03_factcheck_report.md 確認
  ├─ 差し戻し → 02_writer に修正指示（ループ）
  └─ OK / 要修正（軽微） → 04_image-creator に指示
  ↓
shared/04_image_report.md 完成確認
  ↓
output/ に最終成果物を格納
  ↓
[完了レポート出力]
```

---

## 各エージェントへの指示テンプレート

### 01_trend-researcher 起動時

```
【調査依頼】
テーマ：[テーマ名]
調査期間の目安：過去[X]ヶ月以内の情報を優先
特に重視するカテゴリ：[カテゴリ]
出力先：shared/01_research_report.md
完了後：このオーケストレーターに報告
```

### 02_writer 起動時

```
【執筆依頼】
参照ファイル：shared/01_research_report.md
記事の方向性：[方向性メモ]
文字数目安：[文字数]字
出力先：shared/02_article_draft.md
完了後：このオーケストレーターに報告
```

---

## 品質ゲート

各工程完了時に以下を確認してから次工程へ進む。

| 工程 | 確認事項 |
|------|---------|
| リサーチ完了後 | 出典が3件以上ある / 主要キーワードが5個以上ある |
| 記事ドラフト完了後 | 文字数が1,500字以上 / H2見出しが3つ以上 |
| ファクトチェック完了後 | 判定が「OK」または「要修正（軽微）」である |
| 画像レポート完了後 | アイキャッチプロンプトが1件以上ある |

---

## 最終成果物の格納ルール

```
output/
├── articles/
│   └── [YYYY-MM-DD]_[slug].md      ← ファクトチェック済み完成記事
├── images/
│   └── [slug]_[用途]_[連番].png    ← 生成画像
└── reports/
    └── [YYYY-MM-DD]_pipeline_log.md ← パイプライン実行ログ
```

---

## エラー・例外ハンドリング

| 状況 | 対応 |
|------|------|
| エージェントが無応答 | 5分待機後に再指示。3回失敗でログに記録し停止 |
| 差し戻しが3回続く | 人間（ユーザー）にエスカレーション |
| 出典が見つからない | 「出典不明」として記事に明記するか、該当箇所を削除 |

---

## パイプラインログの記録

実行のたびに `output/reports/[YYYY-MM-DD]_pipeline_log.md` を生成し、以下を記録する。

- 実行日時
- テーマ
- 各工程の完了時刻とステータス
- 差し戻し回数
- 最終成果物のファイルパス
